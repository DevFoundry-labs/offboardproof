# Security Status

Threat model and controls are implemented and locally verified.

- External writes default off.
- No account deletion in scope.
- Token digests only; deny-by-default roles.
- Google credentials remain outside persisted workflow data.
- No AI, shell execution, arbitrary paths, or uploaded archives.
- Evidence filenames are generated by the application.

`pip-audit --skip-editable` reports no known vulnerabilities. The tracked-source secret scan has no findings. CodeQL and Dependabot are configured for the public repository.

Residual risks are documented in `docs/security-model.md`.
