# Contributing

Thank you for helping make offboarding evidence more trustworthy.

1. Open an issue for behavioral or schema changes.
2. Create a focused branch from `main`.
3. Add tests for failure, replay, and authorization paths—not only the happy path.
4. Run the commands in the README's Development section.
5. Submit a pull request describing risk, migration impact, and verification evidence.

Never use real employee data, access tokens, service-account keys, or production tenant identifiers in tests or issues. Synthetic examples should use the reserved `.test` domain.

By participating, you agree to follow [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).
